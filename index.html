🏢 VUE D'ENSEMBLE

C.E.O. — Capitalism: Eternal Optimization est un jeu de quiz compétitif deck-building pour 2–10 joueurs (ou 1 vs 9 IAs en Solo). Chaque joueur subit un EEP (Entretien d'Évaluation de Performance) de 10 questions. Le premier à atteindre 100% de Jauge de Suprématie est promu C.E.O. de l'entreprise. Les autres sont licenciés avec style.

💼 Votre souffrance est notre KPI. — Charte de l'Entreprise, Article 1er

🃏 DECK DE CARTES DE COMBAT

C.E.O. est un jeu de deck building. Votre main évolue au fil des EEPs. Les cartes se jouent pendant la Fenêtre de Combat (5s) avant chaque question. Buffer N+2 = l'effet se déclenche 2 questions plus tard.

Distribution thématique : Les cartes droppées en fin d'EEP dépendent du thème joué — Finance donne plus de Multiplicateurs, RH donne plus de Défenses, Tech donne plus d'Intel.

⚔️ SYSTÈME DE COMBAT

⏳ FENÊTRE DE COMBAT (5 secondes)

Avant chaque question, une fenêtre de 5s s'ouvre. Pendant ce temps :

  • Si vous êtes candidat : jouez des cartes Défense ou Multiplicateur
  • Si vous êtes spectateur : jouez des cartes Attaque contre le candidat
  • Les bots jouent leurs cartes automatiquement selon leur stratégie de classe

📁 BUFFER N+2 — MÉCANIQUE CENTRALE

Une carte jouée sur la question Q déclenche son effet sur la question Q+2. Ce délai force l'anticipation stratégique.

Exemple : Un Requin joue Brouillage sur Q3 → vous verrez l'indicateur d'attaque en Q3 mais l'effet s'applique sur Q5. Si vous avez un Antivirus, jouez-le en Q4 pour bloquer.
Attaque visible dans bufferDès que le bot joue la carte
Effet appliqué2 questions après le dépôt
Défense jouée en Q(n-1)Bloque l'attaque de Q(n)

📈 BOURSE AUX THÈMES

La Bourse permet d'acheter/vendre des thèmes entre les EEPs. Le thème acheté devient obligatoire pour le prochain EEP de l'acheteur.

🔄 PHASES D'ENCHÈRE

ÉTAPE 1 — MASQUÉVendeur cache le thème. Acheteurs enchérissent à l'aveugle
ÉTAPE 2 — RÉVÉLÉThème dévoilé. Vendeur accepte, monte le prix, ou retire
PÉNALITÉ RETRAIT−20% du prix de réserve, payé au C.E.O.
INSIDER TRADINGL'Analyste peut révéler le thème masqué (consomme carte Intel)

💼 PORTFOLIO — MAX 2 THÈMES

Limite : Chaque joueur ne peut détenir que 2 thèmes simultanément. Un 3ème déclenche une Restructuration forcée (supprimer un ancien thème pour intégrer le nouveau).

📋 FILE D'ATTENTE — 3 SLOTS

Si une enchère n'est pas conclue ce tour, elle persiste en mémoire jusqu'au tour suivant (max 3 enchères actives simultanées). DORMANT → Interface de gestion de queue à activer.

📊 SNAPSHOT / UNDO DORMANT

Infrastructure de snapshot disponible. Permet d'annuler la dernière action Bourse si aucune réponse n'a été envoyée. Activable via CEO_Snapshot.save() avant chaque action.

💡 TIPS & STRATÉGIES

Buffer N+2 : Une attaque posée sur Q3 frappe en Q5. Gardez un Antivirus pour les questions à fort enjeu (Q8-Q10).
Checkpoints : Atteignez 25% avant de tenter des combos risqués. Le palier est permanent — c'est votre plancher.
Bourse : Achetez des thèmes que vous maîtrisez. Vendez ceux des autres quand ils sont en avance pour perturber leur rythme.
Pression Actionnariale : Ne laissez pas la jauge monter trop vite — si vous êtes dernier quand elle explose, c'est vous qui perdez 15%.
Prêt C.E.O. : Ne prenez un prêt que si vous avez 75⚡ de remboursement possible. La saisie (-15% jauge) est dévastatrice.
Requin + Overclock : Turbo + Double Prime pendant votre EEP = +20s ET 3× points si Requin passif actif.
